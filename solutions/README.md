# Решения задач

Здесь по одной папке на задачу: `solutions/<slug>/<slug>.py`.

- `<slug>` — тема + двузначный номер задачи: `strings_01`, `recursion_47`.
- Модуль импортируется тестами (`tests/test_<slug>.py`), поэтому:
  - никакого кода на уровне модуля, кроме констант;
  - `main()` + `if __name__ == "__main__":` — для демо-запуска;
  - `print` допустим только внутри `main()`.
- Задача может импортировать соседние файлы из своей папки: conftest
  добавляет папку задачи в `sys.path` на время импорта.

Добавляя новую задачу, сначала посмотри на пример:

- [`strings_01`](strings_01/strings_01.py) — простая обработка строк;
- [`recursion_47`](recursion_47/recursion_47.py) — возвращать результат,
  а не печатать;
- [`files_18`](files_18/files_18.py) — свои исключения и обработка ошибок.
