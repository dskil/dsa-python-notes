## Журнал

01. **Удалить цифры и посчитать длину**

   Дана строка. Удалить из неё все цифры и посчитать длину полученной строки.

   Реализуй:
   - strip_digits(text) -> str — строка без цифр (порядок остальных символов сохраняется);
   - digits_free_length(text) -> int — длина результата.

   Цифрами считаются символы, для которых symbol.isdigit() истинно (значит, и арабские, и кириллические цифры вроде '١').

02. **Двоичная запись: единицы и нули**

   Перевести число в двоичную систему, посчитать количество единиц и нулей.

   - to_binary(n) -> str — двоичная запись без префикса 0b;
   - count_ones(n) -> int — единицы;
   - count_zeros(n) -> int — нули (ведущих нулей не считаем: 2534 -> '100111100110').

   Подсказка: bin(n) уже возвращает str вида '0b1010'.

03. **Делители числа**

   Вывести все делители числа, кроме 1 и самого числа.

   - proper_divisors(n) -> list[int] — по возрастанию, без повторов;
   - count_proper_divisors(n) -> int — их количество.

   Оптимально: перебирать делители до math.isqrt(n), добавляя пару d и n // d. Для n = 36 ответ [2, 3, 4, 6, 9, 12, 18], но такие тесты должны работать за миллисекунды.

04. **Соседние пары: нечётные, сумма кратна 5**

   В файле последовательность целых чисел от 1 до 10 000. Считаем пары СОСЕДНИХ элементов.

   - count_special_pairs(numbers) -> int — сколько пар, где оба числа нечётные, а сумма кратна 5;
   - max_special_pair_sum(numbers) -> int — максимальная сумма среди таких пар (0, если пар нет).

   Пример: [15, 20, 25, 30, 35, 45]. Подходит только пара (35, 45): оба нечётные, сумма 80 кратна 5. Ответ: count = 1, max = 80.

05. **Числа ровно с 6 делителями**

   - count_divisors(n) -> int — количество делителей;
   - numbers_with_divisor_count(start, end, divisors=6) -> list[int].

   Ловушка исходника: числа вида p·q с простыми p ≠ q имеют 4 делителя, а p·q·r (три простых сомножителя) — 8; ровно 6 делителей дают p²·q или p⁵. Для [100; 200] таких чисел 9.

06. **Самая длинная подстрока из цифр**

   Дана строка из латиницы и цифр. Найдите самую длинную непрерывную подстроку, состоящую только из цифр.

   - longest_digit_run(text) -> str;
   - longest_digit_run_length(text) -> int.

   Пример: 'a1b23c456de7f8901g45h6'.
   Осторожно: '8901' (4 цифры) длиннее, чем '456' (3) — исходная программа выводила '456', это ошибка.

07. **Числа с ровно 3 единицами в двоичной записи**

   Найдите количество натуральных чисел x из [start; end], для которых в двоичной записи ровно `ones` единиц.

   - numbers_with_ones(start, end, ones=3) -> list[int];
   - count_numbers_with_ones(start, end, ones=3) -> int.

   Пример: числа из [8; 10]: 8 = 1000 (1 ед.), 9 = 1001 (2), 10 = 1010 (2).

08. **Второе по величине число**

   Найти второе по величине (различное) число в списке.

   - second_largest(numbers) -> int;
   - если различных значений меньше двух — ValueError.

   Пример: [5, 3, 9, 1, 9] -> 5. Осторожно: [7, 7, 7] -> ValueError.

09. **Палиндром без пробелов и регистра**

   Проверить, является ли строка палиндромом, игнорируя пробелы, регистр и знаки пунктуации.

   - normalize(text) -> str — оставить только буквы и цифры в нижнем регистре;
   - is_palindrome_loose(text) -> bool — нормализованная строка — палиндром и не пуста.

   'А роза упала на лапу Азора' -> True, 'No lemon, no melon' -> True, '   ' -> False.

10. **Генератор паролей**

   Пользователь вводит длину пароля. Пароль должен содержать минимум: строчную латинскую букву, заглавную, цифру и спецсимвол.

   - generate_password(length=12, alphabet=...) -> str;
   - has_all_categories(password) -> bool;
   - для length < 4 — ValueError;
   - использовать модуль secrets, а не random.

   Тест проверяет 200 паролей: длина и наличие минимум по одному символу каждой категории.

11. **Пересечение двух списков**

   Даны два списка чисел. Найти общие элементы и вывести их в порядке возрастания (без повторов). Если общих элементов нет — строка 'Пусто'.

   - intersection(numbers1, numbers2) -> list[int];
   - format_intersection(numbers1, numbers2) -> str.

   Подсказка: set(a) & set(b).

12. **Случайный логин**

   Сгенерировать случайный логин длины 8 из строчных латинских букв и цифр.

   - make_login(length=8, alphabet=...) -> str;
   - для length <= 0 — ValueError.

   В отличие от исходника (random), используй secrets — логины тоже не должны быть предсказуемы.

13. **Цифры и знаки пунктуации**

   Посчитать в строке количество цифр и количество знаков пунктуации (string.punctuation).

   - count_digits_and_punctuation(text) -> tuple[int, int] — (цифры, пунктуация).

   Тесты сверяют результат со строкой 'Цифр: X' / 'Символы: Y' исходной программы.

14. **Оставить только латиницу и цифры**

   Из строки 'Привет! Как дела? Python3.0' оставить только латинские буквы и цифры.

   - keep_ascii_alnum(text) -> str;
   - кириллица, пробелы, знаки — удаляются.

   Результат для примера: 'Python30'.

15. **Пароль ровно из 10 символов**

   Пароль фиксированной длины 10 должен содержать минимум одну цифру и минимум один спецсимвол.

   - generate_password() -> str;
   - использовать secrets, а не random.

   Тест прогоняет генератор 200 раз.

16. **Запись чисел, сумма, дозапись**

   Работа с файлом чисел (по одному в строке).

   - write_range(path, start, stop) — перезаписать файл числами start..stop включительно;
   - sum_linked_file(path) -> int — сумма чисел;
   - append_range(path, start, stop) — дописать числа в конец.

   Вместо имени файла тесты передают путь во временной папке pytest — не хардкодь 'numbers.txt'.

17. **Безопасное чтение строк**

   Прочитать файл построчно в список строк без символов перевода строки.

   - read_lines_safe(filename) -> list[str];
   - если файла нет — не падать, вернуть [].

   Работа с любым путём (str или pathlib.Path).

18. **Чтение с обработкой ошибок**

   Прочитать текст файла, обработав ошибки собственными исключениями.

   - класс ReadError(Exception) — база;
   - FileNotFoundReadError(ReadError), PermissionReadError(ReadError);
   - read_text_checked(path) -> str — поднимает одно из них.

   Правило: перехватывать FileNotFoundError и PermissionError, а не всё подряд (никаких голых except).

19. **Количество строк в файле**

   Посчитать количество строк в файле.

   - count_lines(filename) -> int.

   Последняя строка без '\n' тоже считается строкой; пустой файл — 0.

20. **Чтение файла порциями**

   Читать файл кусками по chunk_size СИМВОЛОВ (текстовый режим UTF-8 — русская буква не должна разрезаться пополам).

   - read_chunks(filename, chunk_size=1024) -> list[str];
   - для chunk_size <= 0 — ValueError.

   Исходник использовал глобальный цикл, здесь важно оформить это как функцию с параметрами.

21. **Побайтовое копирование**

   Скопировать файл порциями по block_size байт.

   - copy_binary(source, target, block_size=4096) -> int — вернуть число скопированных байт;
   - target перезаписывается, если существовал;
   - для block_size <= 0 — ValueError.

22. **Байты и hex**

   Записать байты в файл и получить их hex-представление.

   - to_hex(raw: bytes) -> str — hex в нижнем регистре;
   - read_hex(filename) -> str — содержимое файла в hex.

   Пример: b'\x00\x01\x02\x03\xFF' -> '00010203ff'.

23. **Случайный выбор и shuffle**

   Тренировка на module random с поддержкой seed (второй аргумент rng) для воспроизводимых тестов.

   - pick_random(sequence, rng=None) — случайный элемент, пустой список — ValueError;
   - shuffle_copy(sequence, rng=None) -> list — перемешанная копия, исходный не меняется;
   - generated_numbers(count, low, high, rng=None) -> list[int].

   Не мутировать входные данные — частая ошибка, которую тесты ловят.

24. **tell() и seek()**

   Прочитать строки position + 1 и position + 2 без символов '\n'.

   - reread_line(filename, position=0) -> tuple[str, str];
   - если строки нет — IndexError.

   В исходнике позиция запоминалась f.tell(), затем f.seek() — здесь важен сам навык позиционирования в файле.

25. **Последние байты файла**

   Прочитать последние count байт файла.

   - read_tail_bytes(filename, count) -> bytes;
   - если файл короче — вернуть весь файл;
   - для count < 0 — ValueError.

   Подсказка: f.seek(-count, 2) не работает при коротком файле — нужен максимум с нулём.

26. **Замена в файле**

   Заменить подстроку во всём содержимом файла.

   - replace_in_file(filename, old, new) -> int — количество замен;
   - файл перезаписывается целиком, путь может быть str или Path.

27. **Временный файл**

   Записать байты во временный файл и прочитать их обратно.

   - write_and_read_temp(payload=b'temp data') -> tuple[str, bytes, str] — (имя файла, содержимое, hex);
   - после выхода файл удаляется автоматически (tempfile.NamedTemporaryFile).

28. **Фильтрация лога по уровню**

   Из лога вида '2024-01-01 10:00:01 [ERROR] Boom' отобрать строки с нужным уровнем.

   - filter_level(lines, level='ERROR') -> list[str];
   - уровень — второй токен строки в квадратных скобках;
   - битые строки (меньше трёх токенов) не должны ронять функцию.

   Исходник умел только ERROR; обобщи уровнем как параметром.

29. **CSV: выручка по товарам**

   В CSV колонки product, quantity, price. Посчитать выручку каждого товара.

   - revenue_by_product(path) -> dict[str, int];
   - для пустого файла — {}.

   Используй csv.DictReader вместо ручного разбора индексов.

30. **Информация об изображении**

   Вывести ширину, высоту и режим изображения (Pillow).

   - get_image_info(filename) -> tuple[int, int, str];
   - если это не картинка — ValueError;
   - если файла нет — FileNotFoundError.

   Pillow необязателен: без него тест помечается skip, а функция поднимает RuntimeError.

31. **Факториал**

   Вычислить n! рекурсивно.

   - factorial(n) -> int;
   - 0! = 1;
   - для n < 0 — ValueError.

32. **Фибоначчи (наивная рекурсия)**

   n-е число Фибоначчи: F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2).

   - fib(n) -> int;
   - для n < 0 — ValueError.

   Это O(φ^n) — так и задумано; сравни с задачей №44.

33. **Сумма цифр числа**

   Сумма цифр неотрицательного числа, только рекурсией (без str).

   - digit_sum(n) -> int;
   - цифры берём через n % 10 и n // 10;
   - для n < 0 — ValueError.

34. **Пути: +1 и ×2 (DP)**

   Сколько способов дойти от start до end шагами +1 и ×2, причём ×2 разрешено только из уже достижимой клетки start.

   - count_paths(start, end) -> int;
   - 1 <= start <= end, иначе ValueError.

   Решается динамикой: dp[i] = dp[i-1] + dp[i/2] (если i чётное и i/2 >= start).
   Проверь на примерах: (1, 5) -> 4, (3, 25) -> 28.

35. **Кузнечик: +1 и +2**

   Сколько способов попасть из клетки start в end прыжками на 1 и на 2.

   - kuznechik(start, end) -> int;
   - 0 <= start <= end, иначе ValueError;
   - если start == end или end == start + 1 — ровно 1 способ.

36. **Способы дойти (рекурсия)**

   Чистая рекурсия без DP: число путей от current до target шагами +1 и +2, пути должны ЗАКАНЧИВАТЬСЯ ровно в target.

   - count_ways(current, target) -> int;
   - если current > target — 0, если равно — 1.

   Примеры: (1, 3) -> 2 (1→2→3 и 1→3), (1, 5) -> 5.
   Сравни с №34/№35: та же идея, разные подходы — это и есть тренажёр.

37. **Сумма 1..n**

   Сумма чисел от 1 до n рекурсией.

   - sum_to_n(n) -> int;
   - sum_to_n(0) = 0;
   - для n < 0 — ValueError.

38. **Разворот строки**

   Развернуть строку рекурсией, без срезов [::-1].

39. **Сумма цифр (вариант 2)**

40. **Палиндром рекурсией**

   - is_palindrome(word) -> bool;

41. **НОД (алгоритм Евклида)**

42. **Возведение в степень (линейное)**

43. **Количество элементов списка**

45. **Сумма вложенных списков**

46. **Бинарный поиск**

47. **Ханойские башни**

   Перенести n дисков с первого стержня на третий.

   - hanoi(n, source='A', target='C', aux='B') -> list[tuple[str, str]] — список ходов (откуда, куда);

   Верни ходы, а не print — так их можно проверить и переиспользовать. Обязательно, чтобы - каждый ход перекладывал один диск, - меньший диск никогда не лежал на большем.

48. **Слияние двух отсортированных списков**

   Слить два отсортированных списка в один отсортированный.

   - не изменять входные списки;

50. **Все подмножества (power set)**
