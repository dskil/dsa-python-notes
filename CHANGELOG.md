# История изменений

## [0.1.0] — 2026-11-17

Первый публичный релиз: тренажёр, каталог, CLI, документация и CI.

### Добавлено

- **86 задач** по темам: строки, битовые операции, числа, списки, файлы,
  рекурсия, словари, множества, исключения. У каждой — условие,
  эталонное решение и собственный файл тестов.
- Пакет `dsa_trainer`: загрузка каталога (`catalog.py`), журнал прогресса
  (`progress.py`) и CLI с командами `list`, `show`, `run`, `stats`, `reset`.
- Фикстура `solution` и хелпер `assert_case` в `tests/conftest.py`:
  сценарии «вход → ожидание», ожидаемые исключения, строгий тип результата.
- `tools/build_catalog.py` — генерация `docs/tasks.md` из каталога
  и режим `--check` для CI.
- `tools/make_todo.py` — превращает решения в заготовки с `NotImplementedError`
  (с резервной копией `*.bak`), чтобы решать задачи самому.
- `tools/smoke_cli.py` — сквозная проверка всех команд CLI.
- GitHub Actions: `tests.yml` (Linux/macOS/Windows × Python 3.10/3.12, lint),
  `docs.yml` (контроль свежести `docs/tasks.md`), `publish.yml` (PyPI по тегу).
- pre-commit с ruff, `.editorconfig`, `.gitattributes`, модель PR.
- Документация: README, CONTRIBUTING, MIT-лицензия.

### Исправлено относительно исходных тренировочных скриптов

- «Самая длинная подстрока из цифр» в `Train6`: `8901`, а не `456`.
- Числа с ровно 6 делителями на [100; 200]: 11 чисел, включая 124, 148,
  153, 172.
- `remove_vowels`: `AEIOU` теперь тоже удаляются.
- `Train34`: шаг `×2` не позволяет прыгнуть левее стартовой клетки.
- `Train47`: явная верхняя граница `hanoi(30)` и ленивый `hanoi_iter`.
- `hanoi`, `insert_at`, `generate_password`: больше не мутируют аргументы,
  фейковые заглушки не проходят тесты.

### Известные ограничения

- Задача №30 (информация об изображении) требует Pillow и помечается
  `skipped`, если библиотека не установлена.
- `docs/tasks.md` генерируется, не редактируется руками.
